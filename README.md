# William Kahare Matenjwa — Personal Portfolio

A personal portfolio website built with HTML and CSS.

## Live Site

[View Portfolio](https://willyk-77.github.io/portfolio/)

---

## Sections

- **Hero** — Introduction and call to action
- **About** — Background and personal story
- **Skills** — HTML, CSS, JavaScript
- **Projects** — Three project showcase cards
- **Contact** — Message form
- **Footer** — Social media links

---

## Built With

- HTML5
- CSS3 (Flexbox, Media Queries)

---

## Features

- Fixed navigation header
- Smooth scroll between sections
- Responsive design for mobile and desktop
- Hover effects on cards and buttons
- Dark theme
